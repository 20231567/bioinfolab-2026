# 이 저장소의 규칙

## 이 저장소는
생물정보학실험 수업의 실습 저장소이다. 주차별로 labNN 폴더가 있다.

## 코드를 쓸 때
- FASTA 파일은 `lab07/src/fasta.py` 의 `read_fasta` 함수로 읽는다.
- 새 라이브러리(Biopython 등)를 쓰기 전에 먼저 사용자에게 물어보고 허락을 받는다.
- 주석은 한국어로 상세하게 작성한다. 

## 하지 말 것 (금지 명령어)
- `rm` 으로 파일을 삭제하지 않는다.
- `pip install` 로 패키지를 임의로 설치하지 않는다.
- `git` 관련 명령어를 에이전트가 직접 실행하지 않는다.
