# qual_by_position.py 사용법

FASTQ 파일의 모든 read에서 **같은 위치**(1번째 염기, 2번째 염기, …)의 품질 점수를 모아
위치별 평균을 계산하고, `위치<TAB>평균 품질` 형식으로 출력하는 스크립트이다.
FastQC의 **Per base sequence quality** 그래프가 계산하는 평균값과 같다.

## 1. 실행 방법

`lab11/` 폴더에서 실행한다.

```bash
cd lab11
# 화면에 출력
python3 src/qual_by_position.py data/SRR1553607_1.fastq
# 파일로 저장
python3 src/qual_by_position.py data/SRR1553607_1.fastq doc/qual_by_position.tsv
```

| 인자 | 설명 |
|------|------|
| `<FASTQ파일>` | 입력 FASTQ (필수, `.gz` 압축 파일도 가능) |
| `[출력파일]` | 결과를 저장할 파일 (생략하면 화면에 출력) |

## 2. 출력 형식

헤더 없이 한 줄에 한 위치씩, 탭으로 구분한다. 평균은 소수점 둘째 자리까지 쓴다.

```text
1	32.04
2	32.17
3	32.28
...
101	28.25
```

## 3. 계산 원리

1. FASTQ는 4줄이 read 하나이다 (`@이름` / 서열 / `+` / 품질 문자열).
2. 품질 문자 하나가 염기 하나의 점수이다. **Phred+33** 인코딩이므로
   `점수 = ord(문자) - 33` (예: `I` → 40, `5` → 20, `!` → 0).
3. 위치 i마다 `점수 합계`와 `read 수`를 누적하고, 마지막에 `합계 / read 수`로 평균을 낸다.
4. read 길이가 달라도(트리밍 후 등) 각 위치는 **그 위치까지 염기가 있는 read만**으로 평균을 낸다.
5. 파일을 4줄씩 읽으므로 큰 파일도 메모리를 많이 쓰지 않는다.

## 4. 오류 처리

| 상황 | 메시지 | 종료 코드 |
|------|--------|-----------|

## 5. 테스트 결과

### (1) 손으로 계산 가능한 작은 파일 (`data/test.fastq`)

```text
@r1  ACGT  품질 IIII  → 40 40 40 40
@r2  ACGT  품질 !!!!  →  0  0  0  0
@r3  AC    품질 5+    → 20 10
```

| 위치 | 계산 | 기대값 | 출력 |
|------|------|--------|------|
| 1 | (40+0+20)/3 | 20.00 | 20.00 |
| 2 | (40+0+10)/3 | 16.67 | 16.67 |
| 3 | (40+0)/2 | 20.00 | 20.00 |
| 4 | (40+0)/2 | 20.00 | 20.00 |

길이가 다른 read(r3은 2bp)가 섞여도 3·4번 위치는 r1, r2만으로 평균을 낸다.
오류 상황 3가지(인자 없음, 파일 없음, FASTA 파일 입력)와 `.gz` 입력도 확인했다.

### (2) 실제 데이터 `data/SRR1553607_1.fastq`

- read 203,445개, 모두 101bp → 위치 101개, 실행 시간 약 2초
- 1번 위치 32.04에서 올라가 14번 위치에서 최고(38.47)가 되고, 이후 read 뒤쪽으로
  갈수록 낮아져 101번 위치는 28.25이다. 87번 위치부터 평균이 30 아래로 떨어진다.
- PDF 마지막 쪽에 원본과 trimmed 결과를 겹친 위치별 평균 품질 그래프를 넣었다.

### (3) FastQC 결과와 비교

`doc/SRR1553607_1_fastqc.zip` 안의 `fastqc_data.txt`(Per base sequence quality의 Mean 열)와 비교했다.
FastQC는 1~9번은 위치별로, 10번 이후는 `10-11`, `12-13` 처럼 구간으로 묶어 보여 주므로,
구간은 스크립트 값의 평균을 내어 비교했다.

| 위치 | 스크립트 | FastQC |
|------|----------|--------|
| 1 | 32.04 | 32.04 |
| 2 | 32.17 | 32.17 |
| 3 | 32.28 | 32.28 |
| 98-99 | 29.08 | 29.08 |
| 100-101 | 28.59 | 28.59 |

55개 구간 모두 일치했다(최대 차이 0.005, 소수점 반올림 차이).

### (4) 트리밍 후 데이터 `data/trimmed.fastq`

```bash
python3 src/qual_by_position.py data/trimmed.fastq doc/qual_by_position_trimmed.tsv
```

read 188,357개. fastp로 저품질 부분을 잘라내어 101번 위치 평균이 28.25 → 30.17로 올라갔다.
